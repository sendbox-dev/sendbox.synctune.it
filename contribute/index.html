Contributor guide

Contribute to SendBox

Both projects are Apache-2.0 and developed in the open on GitHub.

For larger changes, open an issue first to discuss the approach. Use synthetic data in tests and examples, and never commit real credentials, tokens or personal data. Report vulnerabilities privately, not in issues or pull requests.

SendBox

The CLI, runtimes and guest services live in sendbox-dev/sendbox. The Rust toolchain is pinned in the repository.

Documentation and this website

The documentation pages on this site are published unchanged from each project's repository at a recorded commit. To fix or extend a page, change the document in its project repository; each page links to its source and has an edit link. The site is updated by syncing to a newer commit.

The website itself is plain HTML and CSS with no dependencies. Its source, sync and check scripts are in sendbox-dev/sendbox.synctune.it; see its maintenance guide.

SendBox and SendBox Fleet are open source under the Apache License 2.0, built in the open by Synctune Open.
