Security

Please report suspected vulnerabilities privately through GitHub private vulnerability reporting (the repository's Security tab, then Report a vulnerability). Do not open public issues or pull requests for vulnerabilities.

The security design is described in docs/threat-model.md. This service is a scaffold: it authorizes nothing yet and must not be deployed as a governance authority.

Published from SECURITY.md in sendbox-dev/sendbox-fleet at commit 962a6cf. To change this page, edit it in sendbox-dev/sendbox-fleet; the site picks it up on the next sync.
