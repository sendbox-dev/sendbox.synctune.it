SendBox

Give your coding agent a workspace, not your whole machine.

SendBox is an open-source Rust CLI for running coding agents in dedicated Linux VMs on macOS and Linux. Keep your terminal workflow while explicitly choosing the files, network destinations, credentials and MCP tools a session can use.
